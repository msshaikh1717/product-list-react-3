# Product List with Cart

Frontend Mentor challenge solution. React e-commerce product grid with interactive shopping cart and order confirmation flow.

## Tech Stack

* React 19
* Create React App (CRA)
* Vanilla CSS
* JavaScript ES6+

## Features

* Populates UI dynamically using local `data.json`.
* Cart state management: add, remove, increment, and decrement items.
* Order confirmation modal displaying selected items and total price.
* "Start New Order" action resets app state.
* Fully responsive layout (mobile and desktop).
* Keyboard accessible navigation.

## Local Development

1. Clone repository.
2. Install dependencies:
```bash
npm install

```


3. Start development server:
```bash
npm start

```


4. Build for production:
```bash
npm run build

```
